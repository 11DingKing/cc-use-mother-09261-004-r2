# 课堂反馈闭环

纯 Python 服务端项目：教材反馈的登记、指派、修订与撤回，基于追加式事件日志。

- 每条反馈登记时必须指定负责人与有效期限，可改派，全程留痕。
- 所有变更（提交、改派、修订、状态流转、撤回）都是追加的事件，只插不改；撤回只是追加一条撤回记录，原反馈与每次修订都保留在 `GET /feedbacks/{id}/history`。
- 单一当前版本：命令必须带 `expected_version`，过期版本与非法流转一律拒绝；幂等键去重，重复提交返回原反馈；事件插入即事务，服务重启后按日志重放恢复，同一条反馈不会有两个当前版本。

测试命令：python3 -m unittest discover -s tests -v

编译命令：python3 -m compileall -q service_09261_004 tests
